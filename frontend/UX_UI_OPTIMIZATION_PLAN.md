## 一、当前设计系统现状分析

## 二、优化计划（按优先级分批）

### Phase 1 — 基础统一（预计 2-3 天）

#### P1.1 设计系统清理
- **修复 `page-container` padding**：`padding: 0` → `padding: var(--spacing-lg)`
- **修复 el-card shadow/border 冲突**：统一为 border-only 方案
- **消灭内联颜色**：grep 所有 `style="color:rgb` 替换为 CSS 变量
- **统一 border 变量**：所有卡片容器统一用 `var(--border-color)` 或 `var(--border-light)`

#### P1.2 字体规范化
- **禁止非标准字号**：移除 `0px`、`13.3333px` 等值，对齐 8 级字号系统
- **定义 `--lh-tight` / `--lh-normal` / `--lh-relaxed`** 行高变量
- **添加展示字体**：标题用 `font-weight: 600` + `letter-spacing: -0.02em` 增强层次

#### P1.3 间距统一
- 所有组件的 padding/margin 改用 `var(--spacing-*)` 系列
- 审计并修复组件间不一致的间距值

### Phase 2 — 训练中心核心页面（预计 3-4 天）

**具体改动：**

4. **步骤状态色条**：左侧色条表示该步骤的评分状态（未评/已评/自动评分）
5. **学生切换动画**：内容区添加 fade 过渡

### Phase 4 — 交互增强（预计 2 天）

#### P4.1 全局微交互增强
- **加载状态**：关键列表添加骨架屏（Skeleton）而非 v-loading 全遮罩
- **操作反馈**：提交评分后添加成功 toast + 自动跳转下一位
- **空状态重设计**：为不同场景定制空状态（无提交/无任务/无数据）
- **表格行 hover**：添加左侧色条指示

#### P4.2 响应式增强
- **平板双栏**：768-1024px 下批阅工作台改为上下分栏
- **训练卡片**：768px 以下卡片改为水平布局
- **首页统计**：平板下 4 卡片变 2x2 网格

### Phase 5 — 品牌一致性（预计 1 天）

#### P5.1 品牌元素统一
- 所有页面标题区统一使用 `--primary-light` 背景色块
- 所有数据可视化（图表、进度条）统一使用品牌色谱
- 空状态插画统一风格
- 版本号从登录页移除或放入"关于"页面

## 五、实施建议

1. **Phase 1 优先**：设计系统清理是所有后续优化的基础，必须先做
2. **逐模块验证**：每个 Phase 完成后运行 `npm run dev` 实际查看效果
3. **暗色模式同步**：所有改动必须同步验证暗色模式
4. **移动端回归**：每个 Phase 完成后用 DevTools 模拟移动端检查
5. **渐进式发布**：可以按 Phase 分批合并，不必等全部完成
