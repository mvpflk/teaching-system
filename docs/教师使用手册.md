## 一、登录系统

### 1.1 打开系统

在浏览器地址栏输入学校给你的网址（例如 `http://xxzx.edu.cn` 或 `http://192.168.1.100`）。

### 1.2 输入账号密码

| 你是 | 账号由谁提供 | 默认密码 |
|------|-------------|---------|
| 教师 | 系统管理员创建 | `123456`（首次登录后请修改） |

### 1.3 修改密码

登录后，点击右上角你的名字 → **修改密码** → 输入旧密码和新密码。

## 二、布置作业/发布任务

### 2.1 创建新作业

1. 点击左侧菜单 **任务管理** → **发布任务**
2. 点击右上角 **+ 新建任务**
3. 填写任务信息：

   | 字段 | 怎么填 |
   |------|--------|
   | 任务标题 | 例如"第三章 课后练习" |
   | 学科 | 选择你教的科目 |
   | 任务类型 | 选"课后作业" |
   | 班级 | 勾选要发布的班级（可以多选） |
   | 截止时间 | 设置学生最晚提交时间 |
   | 题目 | 可以手动录入，也可以用 AI 自动生成（见第六节） |

4. 点击 **保存为草稿**（还可以修改）或 **直接发布**（学生立即收到）

### 2.2 发布草稿

在任务列表中，找到状态为"草稿"的任务，点击右侧 **发布** 按钮。

### 2.3 查看哪些学生交了

在任务列表中点击任务标题 → **提交情况** 标签页：
- 绿色 = 已提交
- 黄色 = 未提交
- 红色 = 逾期未交

点击 **提醒未交学生**，系统会自动给这些学生发通知。

## 三、创建在线考试

### 3.1 新建考试

1. **任务管理** → **发布任务** → **+ 新建任务**
2. 任务类型选 **考试**
3. 设置考试时长（如 45 分钟）

### 3.2 添加题目

有三种方式：

**方式 A：从题库选（推荐）**
- 点击 **从题库选题**
- 按学科、知识点、题型筛选
- 勾选需要的题目 → **加入试卷**

**方式 B：AI 自动出题**
- 点击 **AI 智能出题**
- 输入知识点（如"函数的基本性质"）
- 选择题型和数量
- 点击 **生成** → 预览 → **确认添加**

**方式 C：手动录入**
- 点击 **+ 添加题目**
- 选择题型（单选/多选/判断/填空/简答）
- 输入题目、选项、答案、解析

### 3.3 考试设置

| 设置项 | 说明 |
|--------|------|
| 切屏警告次数 | 学生切出考试页面几次算违规（建议 3 次） |
| 自动交卷 | 到时间后系统自动提交 |
| 显示成绩 | 考完是否立即让学生看到分数 |
| 防作弊模式 | 开启后禁止复制粘贴、切屏警告 |

### 3.4 发布考试

保存后点击 **发布**，学生在规定时间内登录系统就能看到考试。

## 四、批改学生作业

### 4.1 批改客观题（单选/多选/判断/填空）

系统会在学生提交时**自动批改**，不需要你动手。

### 4.2 批改主观题（简答/作文/实操）

1. **任务管理** → **任务列表** → 点击任务标题
2. 进入 **待评分** 标签页
3. 点击学生名字 → 看到学生答案和参考答案
4. 输入分数和评语 → **提交评分**

### 4.3 使用 AI 辅助评分（简答题）

1. 在评分页面点击 **AI 评分建议**
2. 系统会显示 AI 给出的分数和建议
3. 你可以 **采纳** 或 **自己打分**

> AI 评分仅供参考，**最终分数由你决定**。如果 AI 评分置信度低（显示橙色标签），建议人工复核。

### 4.4 打回重交

如果学生提交的作业不合格：
1. 在评分页面点击 **打回重交**
2. 输入打回原因（如"答案不完整，请补充"）
3. 学生会收到通知，修改后重新提交

### 4.5 一键导出成绩

点击 **导出成绩** 按钮，系统生成 Excel 表格，包含：
- 全班每个学生的得分
- 每道题的得分率
- 平均分、最高分、最低分

## 五、查看成绩分析

### 5.1 单次任务分析

任务发布后，点击任务标题 → **成绩统计**：

| 你能看到 | 有什么用 |
|---------|---------|
| 分数分布图 | 一眼看出这次考试难不难（倒金字塔形说明太难了） |
| 每道题得分率 | 哪道题全班都不会？下次重点讲 |
| 个人排名（可选） | 可以关闭排名显示，避免伤害学生自尊 |

### 5.2 成绩趋势

**数据中心** → **成绩趋势**：
- 查看某个班级多次考试的成绩变化曲线
- 绿色向上 = 进步，红色向下 = 下滑，需要关注

### 5.3 知识掌握度分析

**精准教学** → **知识图谱**：
- 每个知识点显示全班平均掌握度（百分比）
- 红色 = 薄弱（< 60%），需要补课
- 绿色 = 已达标（> 80%），可以跳过

## 六、使用 AI 辅助出题

### 6.1 智能生成题目

1. **AI 助手** → **智能出题**
2. 填写出题要求：

   | 字段 | 示例 |
   |------|------|
   | 知识点 | "Python 循环结构" |
   | 年级 | 高一 |
   | 题型 | 单选 + 判断 + 填空 |
   | 题目数量 | 15 题 |
   | 难度 | 中等 |
   | 参考教材（可选） | 上传你的教案或教材内容，AI 会据此出题 |

3. 点击 **开始生成**（等待 30-60 秒）
4. 预览生成的题目，可以：
   - ✅ **全部采纳**：一键加入试卷
   - ✏️ **手动修改**：直接编辑题目内容
   - ❌ **删除**：不要的题删掉
   - 🔄 **重新生成**：对结果不满意可以再生成一次

### 6.2 生成诊断报告

**精准教学** → **生成报告**：
- 输入学生姓名或学号
- 选择学科
- 系统自动生成该学生的薄弱知识点分析报告
- 报告中包含：掌握度雷达图、薄弱清单、个性化学习建议

### 6.3 生成巩固练习

AI 可以根据学生的薄弱知识点，自动生成针对性练习题：
1. 在学生报告页面点击 **生成巩固练习**
2. 选择题目数量和难度
3. 系统生成一套针对该学生薄弱点的练习题

## 七、查看学生学情报告

### 7.1 单个学生报告

1. **学生管理** → **学生列表**
2. 点击学生名字
3. 可以看到：

   | 内容 | 说明 |
   |------|------|
   | 各科成绩 | 最近考试的成绩和排名 |
   | 作业完成率 | 这个学生作业交得及时吗 |
   | 课堂表现 | 出勤、回答问题情况 |
   | 成长轨迹 | 一学期以来的进步曲线 |
   | 偏科分析 | 哪科强哪科弱，用雷达图展示 |

### 7.2 全班学情总览

**数据中心** → **班级总览**：
- 全班成绩分布
- 各科平均分对比
- 作业提交率统计
- 知识点掌握度热力图

## 八、管理班级和学生

### 8.1 查看班级

**班级管理** → **我的班级**：查看你教的班级和学生名单。

### 8.2 添加学生

联系系统管理员，通过 Excel 批量导入。也可以单个添加：
1. **班级管理** → 选择班级
2. 点击 **+ 添加学生**
3. 输入学生姓名和学号

### 8.3 重置学生密码

如果学生忘记密码：
1. **学生管理** → 找到该学生
2. 点击 **重置密码**
3. 密码重置为 `123456`，学生登录后自己修改

## 九、常见问题

### Q：我布置的作业学生说看不到？

**原因 1：** 作业还是"草稿"状态，没有点击"发布"
**原因 2：** 没有勾选正确的班级
**原因 3：** 任务还没到开始时间

→ 检查任务状态，如果是"草稿"就点击发布

### Q：学生交错了作业能撤回吗？

可以。在任务详情页 → **提交情况** → 找到该学生 → 点击 **打回重交**。

### Q：AI 出的题有错误怎么办？

AI 偶尔会出错。建议：
1. 生成后**先预览再添加到试卷**，人工核对一下
2. 如果发现错误，可以直接编辑修改
3. 也可以点击 **重新生成** 让 AI 再出一版

### Q：我想把成绩发给家长？

在成绩页面点击 **导出 Excel**，把文件下载下来，通过微信或家校群发给家长。
系统也提供家长端（需单独开通），家长登录后可以查看自己孩子的成绩。

### Q：上课时想让学生做几道题，来不及提前准备？

用 **课堂互动** 功能：
1. **课堂管理** → **发起互动**
2. 选择 **随堂练习**
3. 输入 1-3 道题（或直接从题库选）
4. 点击 **开始**，学生手机端立刻收到
5. 作答结束后，系统自动统计正确率
